# Big Data тренажёр · 6 семестр

Интерактивный тренажёр лабораторных и практических занятий по дисциплине
**«Технологии больших данных (Big Data)»** (направление 60230400 «Компьютерная лингвистика», 3 курс, 6 семестр).

Тренажёр — статический сайт: он работает с **GitHub Pages** без сервера и без установки программ.
Студент открывает ссылку в браузере и сразу пишет код:

* **Python** выполняется прямо в браузере (Pyodide: pandas, numpy, matplotlib, seaborn, wordcloud, requests, BeautifulSoup, sqlite3, scikit-learn);
* **MongoDB** — учебный эмулятор оболочки `mongosh` (CRUD, операторы запросов, агрегации, индексы, текстовый поиск, `mongoimport`);
* **Hadoop HDFS** — терминал с эмулятором кластера (NameNode + 3 DataNode, блоки 128 МБ, репликация, `fsck`, `dfsadmin`);
* **Apache Spark** — эмулятор API PySpark 3.5 (SparkSession, DataFrame, Spark SQL, RDD, окна), код переносится в Colab без изменений.

Каждое задание **проверяется автоматически**, прогресс сохраняется в браузере, в конце студент скачивает **HTML-отчёт** с кодом всех заданий.

## Публикация на GitHub Pages (один раз, ~10 минут)

1. Войдите на [github.com](https://github.com) и создайте **новый публичный репозиторий**
   (**New repository**), например `bigdata-trainer`. Файлы README/лицензию не добавляйте.
2. Загрузите в него содержимое этой папки — любым способом:

   **Через Git (рекомендуется)** — в терминале в папке тренажёра:
   ```bash
   git init -b main          # если репозиторий ещё не создан локально
   git add .
   git commit -m "Big Data тренажёр"
   git remote add origin https://github.com/<ваш-логин>/bigdata-trainer.git
   git push -u origin main
   ```

   **Через GitHub Desktop**: File → Add local repository → выберите папку → Publish repository.

   **Через браузер (из архива)**: распакуйте архив, откройте папку `bigdata-trainer`, а на странице
   репозитория выберите **Add file → Upload files**. Перетаскивайте **содержимое** папки (файлы и подпапки),
   а не саму папку, иначе сайт окажется по адресу `…/bigdata-trainer/bigdata-trainer/`.
   GitHub принимает не больше 100 файлов за раз, поэтому загрузите в два приёма: сначала всё, кроме папки
   `data` (75 файлов) → **Commit changes**, затем папку `data` (82 файла) → **Commit changes**.
   Файл `.nojekyll` желателен (публикация идёт быстрее), но тренажёр работает и без него.
3. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите
   **Source: Deploy from a branch**, ветка **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу
   **`https://<ваш-логин>.github.io/bigdata-trainer/`** — эту ссылку и раздайте студентам.
5. (Для кнопки «Открыть в Colab») пересоберите блокноты с адресом репозитория и отправьте изменения:
   ```bash
   node tools/build_notebooks.js <ваш-логин>/bigdata-trainer
   git add notebooks && git commit -m "Блокноты Colab" && git push
   ```

> После любых изменений файлов увеличьте `BDT_VERSION` в `index.html` (например, `"1"` → `"2"`)
> и параметр `?v=` у скриптов, чтобы браузеры студентов не использовали старую версию из кэша.

## Локальный запуск (без интернета на сервере, но нужен доступ к CDN)

Открыть `index.html` двойным щелчком нельзя (браузер запрещает Web Worker для `file://`). Запустите простой сервер:

```bash
cd bigdata-trainer
python -m http.server 8000
```

и откройте <http://localhost:8000>.

## Для преподавателя

* **Задания** — в файлах `content/l01.js … l08.js`, `content/p01.js … p15.js`. Формат описан в [`content/README.md`](content/README.md).
* **Самопроверка** — страница `selftest.html` выполняет все эталонные решения и проверки (`selftest.html?s=p04,l06` — выборочно). Запускайте её после правки заданий.
* **Отчёт студента** — HTML-файл (страница «Отчёт»): таблица прогресса, результаты тестов, отметки о просмотре эталонных решений, код каждого задания и контрольная сумма.
* **Учебные данные** — папка `data/`, создаются скриптом `python tools/gen_data.py` (все данные вымышленные; корпус — 16 новостных текстов на узбекском языке, написанных для курса). После изменения данных скрипт обновляет `data/manifest.json`.
* **Блокноты** — `node tools/build_notebooks.js <владелец>/<репозиторий>` пересобирает `notebooks/*.ipynb` из заданий.
* Прогресс хранится в `localStorage` браузера студента; на странице «Отчёт» есть экспорт/импорт прогресса для переноса на другой компьютер.

## Как это устроено

| Папка/файл | Назначение |
|---|---|
| `index.html`, `css/`, `js/app.js` | интерфейс: занятия, редактор (CodeMirror), проверки, отчёт |
| `js/py-worker.js`, `js/py-runner.js`, `py/trainer_rt.py` | Python в Web Worker (Pyodide 0.29), выполнение ячеек и проверок |
| `py/pyspark/` | учебный эмулятор PySpark поверх pandas |
| `js/mongo-sim.js` | учебный эмулятор MongoDB/mongosh |
| `js/hdfs-sim.js` | учебный эмулятор кластера Hadoop HDFS и терминала Linux |
| `content/` | занятия (теория, задания, проверки, тесты) |
| `data/` | учебные наборы данных, учебный сайт `data/site/`, учебный REST API `data/api/v1/` |
| `notebooks/` | блокноты Jupyter/Colab |
| `tools/` | генерация данных и блокнотов |

Внешние зависимости загружаются с CDN: Pyodide (jsDelivr), CodeMirror (cdnjs), шрифты (Google Fonts).
Первый запуск Python скачивает около 30 МБ и занимает 10–30 секунд, затем браузер кэширует файлы.

> **Эмулятор ≠ настоящий кластер.** MongoDB, HDFS и Spark здесь — учебные эмуляторы: они повторяют команды
> и формат вывода, чтобы отработать навыки. Раздел «Реальная среда» в каждом занятии объясняет,
> как выполнить ту же работу на настоящих системах.
